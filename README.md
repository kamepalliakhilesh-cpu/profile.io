# Akhilesh Kamepalli — Portfolio & 3D Interactive Web Experience

A high-performance personal portfolio and interactive 3D universe engineered with Three.js, GSAP, and modern web standards.

🌐 **Live Demo:** [https://kamepalliakhilesh-cpu.github.io/](https://kamepalliakhilesh-cpu.github.io/)

---

## ⚡ Highlights
- **Cosmo 3D Scene**: Three.js particle wave sea with gentle cursor repulsion physics and gyroscopic hero core.
- **Dynamic Coding Stats**: Live tracking for LeetCode, GitHub, and Codeforces metrics.
- **Glassmorphic UI**: Ultra-refined dark/light theme switching with smooth GSAP animations and Lenis smooth scrolling.
- **Modular Architecture**: Semantic HTML5, Vanilla CSS design tokens, and lightweight vanilla JavaScript.

## 🛠️ Tech Stack
- **Core:** HTML5, CSS3, JavaScript (ES6+ Modules)
- **3D & Graphics:** Three.js
- **Animations:** GSAP, ScrollTrigger, Lenis Smooth Scroll
- **Server:** Node.js HTTP server for live stats caching & API proxy

---

## 🚀 Running Locally
```bash
# Clone the repository
git clone https://github.com/kamepalliakhilesh-cpu/profile.io.git

# Navigate to project directory
cd profile.io

# Start the local development server
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
